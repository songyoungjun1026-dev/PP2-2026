# 건강관리 프로그램 (Health Management)

## 1. 프로젝트 소개
환자의 기본 정보와 신체 정보를 입력하고 BMI를 계산하여 건강 상태를 확인할 수 있는 건강관리 프로그램입니다.

## 2. 주요 기능
- 환자 정보 추가
- 환자식별번호 자동 생성
- BMI 자동 계산
- BMI에 따른 건강 상태 분류
- 환자 정보 파일 저장 및 불러오기

## 3. 사용 기술
- Python
- JSON: 환자 정보 저장 및 불러오기
- CSV: 환자 정보를 표 형식으로 저장
- Pickle: 환자 객체 저장 및 불러오기
- OS: 파일 경로 확인 및 관리

## 4. 파일 구성
- `main.py`: 프로그램 실행 및 메뉴 관리
- `Healthrecord.py`: 환자 정보 및 건강관리 기능
- `data/data.json`: 환자 정보 저장 파일

## 5. 실행 방법
1. Python을 실행합니다.
2. `main.py` 파일을 실행합니다.
3. 화면에 표시되는 메뉴에서 원하는 기능을 선택합니다.
4. 환자 정보를 입력하면 BMI와 건강 상태가 자동으로 계산됩니다.

## 6. BMI 계산 공식

BMI = 몸무게(kg) / 키(m)²

## 7. 개발 목적
Python의 클래스, 객체, 리스트, 조건문 및 파일 입출력을 활용하여 환자 정보를 효율적으로 관리하는 프로그램을 제작하는 것을 목적으로 합니다.
